# ---------------------------------------------------------------------------
# Runtime dependencies.
#
# Kept deliberately small so the project builds on a free hosting tier.
#
# Heavy optional dependencies (torch, torchvision, easyocr) are NOT here: they
# add roughly 3 GB of wheels, which no free tier can build. They live in
# requirements-ml.txt. The application runs without them - the equipment image
# classifier guards its torch import and reports an explicit "fallback" source,
# and the OCR provider degrades to "heuristic".
#
# Note: in this file every non-blank line must start with '#' or be a valid
# PEP 508 requirement. A stray character on its own line makes pip fail with
# "Invalid requirement", which is exactly how this file broke a Docker build.
# ---------------------------------------------------------------------------
